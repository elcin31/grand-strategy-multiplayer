DOMINION 2.3 — GRAND STRATEGY EVOLUTION
Standalone Android playtest

Версия, исходный коммит, точный APK SHA256 и результаты всех обязательных
проверок указаны в MANIFEST.json. SHA256SUMS содержит хеш каждого файла архива.

Установка: откройте включённый APK на Android. Устанавливайте его поверх
предыдущей Dominion: package name и подпись сохранены. Expo Go и Metro не нужны.
Одиночная кампания работает со встроенными ресурсами; multiplayer использует
существующий backend Dominion.

В обновлении: постоянные планы ИИ, совместные мирные требования, реальные
торговые потоки и прогнозы, добровольное автоматическое строительство,
политические группы, четыре оригинальные цепочки событий, связанные фокусы
и проверяемый сценарий «Рейнский пакт восстановления».

reports/ содержит измерения, исходные результаты проверок и скриншоты.
sources/Dominion-source.tar содержит точные исходники и существующие workflows
для воспроизведения сборки. Коммит APK и коммит инструментов проверки разделены
в MANIFEST.json; проверена идентичность runtime между ними.

Камера проверена на Android-эмуляторе API35/SwiftShader в сопоставимых сценах.
Эти результаты не доказывают FPS физического Xiaomi Redmi Note12.
